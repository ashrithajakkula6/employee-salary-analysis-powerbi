# Employee Salary Analysis Dashboard (Power BI)

## Project Overview
This project presents an interactive Power BI dashboard that analyzes employee salary data.  
The dashboard helps understand salary distribution across departments, education levels, experience, gender, and cities.

## Objectives
- Analyze employee salary patterns
- Identify departments with highest salary expenditure
- Understand salary growth based on experience
- Explore employee distribution by gender and city

## Tools Used
- Microsoft Power BI
- Excel / CSV Dataset
- Data Visualization Techniques

## Dashboard Features
- KPI Cards showing:
  - Total Salary
  - Average Salary
  - Total Employees
- Salary analysis by department
- Salary comparison by education level
- Salary trend based on experience
- Employee distribution by gender
- Employee count by city
- Interactive filters for department, gender, and city

## Key Insights
- Certain departments have higher salary expenses.
- Employees with higher experience tend to receive higher salaries.
- Salary varies based on education level.
- Employee distribution differs across cities.
